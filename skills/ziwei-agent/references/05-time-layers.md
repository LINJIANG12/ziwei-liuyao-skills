# 05 时间层：大限/流年/流月/小限

> 何时读：核对「某年/某月发生某事」时。

## 时间层分工

| 层 | 主事 | 说明 |
|---|---|---|
| 大限 | 十年主线 | 每十年一大限，从命宫起运；顺逆行按生年阴阳与性别 |
| 流年 | 当年外应 | 环境与众人之事；以当年太岁地支落宫为流年命宫 |
| **小限** | **当年个人内应** | 个人事件与内部状态；按生年支三合起宫（寅午戌→辰、申子辰→戌、巳酉丑→未、亥卯未→丑），男顺女逆、每虚岁一宫（虚岁 = 农历年差口径） |
| 流月 | 月内细节 | 该公历月覆盖的 1-2 个农历月柱（跨月柱） |
| 流日/流时 | 日内 | 只含日干/时干四化与日系/时系流耀，无主星 |

## 调用规则

- **某年事件**：`year-facts --candidate-key <key> --year <YYYY>` → 返回大限/流年/小限
- **某年某月开始/结束某事**：必须用 `--solar-month <M>`——自动展开为该公历月覆盖的**全部流月**（通常两个月柱）逐个核对；不得自行把公历月换算成农历月，不得只用单月判断
- **全部候选对比**：`year-comparison --year [--solar-month]` 一次看差异，再对 2-3 个关键候选取详情，不逐盘穷举
- 事件年份早于出生或超范围时返回 `out_of_range`/`daXianUnavailable`：应先向用户核实事件年份，**不要据此排除或锁定时辰**

## 解读口径

- 大限主十年主线、流年主当年外应、小限主当年个人内应（**涉及个人事件与内部状态优先看小限**）
- 几个月内的详细趋势以流月盘面为准，年盘只作背景
- 未取回的时间层不得下结论
