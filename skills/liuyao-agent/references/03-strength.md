# 03 旺衰计算纪律

> 何时读：涉及未来区间、应期、指定日期、「什么时候/多久」时（必读）。**正式推演必须先调用 `strength`。**

## 强制纪律

- 涉及未来区间、指定日期、应期、什么时候或多久的问题，**必须先调用 `strength` 取得旺衰事实再写判断**
- 工具失败或没有结果时，**不得自行外推**旺衰，须明确说明缺少时点依据
- 范围样本是**附加事实**：不改卦、不改动爻、不生成吉凶结论；模型必须在工具返回后再写对应时间判断

## 时间单位规则（scope）

| 问题跨度 | scope | target 格式 |
|---|---|---|
| 跨年/多年 | `annual` | `2027年` 或 `甲辰月甲申年` |
| 一年以内/月内 | `monthly` | 该干支月内的公历起始日（不得早于起卦日期），覆盖到同一干支月最后一天并返回每日紧凑样本 |
| 五日 | `five_day` | 五日区间首日 |
| 当日 | `intra_day` | 当天日期或具体时刻，覆盖到当日 23:59 |

**target 也支持**：今天/今日/本日/today、明天/明日/tomorrow、后天/后日、相对日期加时间（今天19点、todayT19:00:00+08:00）、公历日期（2026-07-29、2026/07/29 19:00、2026年7月29日19点）、ISO 日期时间和时辰（今天戌时、2026-07-29戌时）。

## monthly 覆盖语义（必读，防误读）

- `monthly` 的覆盖区间 = **target 日起 → 同一干支月最后一天**，每日一个样本。target 就是「从哪天开始看」
- **起卦日临近/处于月内时，target 传起卦当天只会得到「起卦时刻 → 月末」的残月样本**（可能只有 1 天），**不是完整月**。例：8/7（乙未月最后一天）起卦，target=8/7 只返回 8/7 一天
- 输出里的 `partialMonth: true` + `coverageNote` 会明确标注这一点（工具已自动提示）；看到提示不要当完整月用
- **要拿完整月数据**：分次查询——target 传该月第一天即可覆盖整月（target 不得早于起卦日；起卦日之后的月份直接传月初日期）
- 覆盖天数显著短于整月时，先确认用户要的是完整月还是仅剩余区间，再决定是否分段查询

## 其它规则

- 相对日期以**保存的起卦时间**为锚点；月内/五日/日内范围不得从起卦日期之前开始
- 干支日每 60 天重复：**不能把甲辰日当作唯一日期**；需要干支月年时用干支月干支年单位
- 单轮最多 12 个不同目标（`query_limit_reached` 是正常额度反馈）；重复范围直接复用结果，达到上限后立即使用已有结果输出正文
