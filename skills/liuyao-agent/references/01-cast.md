# 01 起卦

> 何时读：起卦时。

## 起卦前

- 先与用户确认**所问之事**（一事一卦）：感情、事业、财运、健康、出行、应期等
- 问事表述要具体（如「当前工作是否稳定」「三个月内能否换到理想工作」）
- 必要时追问关键背景，但不过度访谈

## 起卦方式

`cast` **只支持三种方式**：

| 方式 | 参数 | 说明 |
|---|---|---|
| 随机算法 | （默认）`[--seed 整数]` | 三枚铜钱法真随机（1/8-3/8-3/8-1/8 传统概率）；`--seed` 仅用于确定性复现，不是独立起卦方式 |
| 手动摇卦 | `--lines <6位背数>` | 逐爻录入，每位 0-3（0=三字老阴 1=少阳 2=少阴 3=三背老阳），如 `--lines 112302` |
| 用户指明 | `--name <本卦名> [--changed-name <变卦名>]` | 说卦名起卦；变卦缺省或相同 = 静卦；**必须带 `--timestamp`（起卦时间）** |

- 卦名支持简称（乾/泰/姤）、全名（乾为天/天泽履/火天大有）、「X卦」后缀（乾卦）
- `--timestamp` 为起卦时间（排四柱/旬空用）：用户指明必填；随机与手动摇卦缺省取当前时刻
- 起卦方式记录在输出 `method`：`imported`（用户指明/手动录入）/ `coins`（随机算法）
- `--name` 与 `--lines` 互斥，一次只选一种方式

## 输出结构（cast）

- **本卦**（originalHexagram）与**变卦**（changedHexagram）：卦名 + 六爻阴阳
- **六爻**：1 为初爻、6 为上爻；爻值为 young_yang/old_yin 等（old=动爻）
- **干支四柱**：年/月/日/时（如 丙午年 乙未月 壬子日 丙午时）
- **旬空**（xunKong）：当前日柱对应的空亡地支（如 寅、卯）

## 规则

- 动爻（old_yin/old_yang）产生变卦；变卦反映事态发展
- 旬空爻位：该地支所临爻位在应期判断中「暂空」，出空（值日）后应事
