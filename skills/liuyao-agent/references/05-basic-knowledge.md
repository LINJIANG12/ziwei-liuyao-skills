# 05 简易知识：六亲、用神与旺衰

> 何时读：解读引用。本文件为公开简易版（公共领域常识级）；完整知识库属私有资产（见仓库 `assets-private/` 说明）。

## 六亲

六爻纳甲后每爻配五行，与日干（或卦宫五行）的生克关系定六亲：

- **父母**：生我者。主文书、长辈、房屋、车辆、庇护
- **兄弟**：同我者。主同辈、竞争、破财（兄弟劫财）、合作
- **子孙**：我生者。主晚辈、福神、医药、解忧（子孙制鬼）
- **妻财**：我克者。主钱财、妻子、物质
- **官鬼**：克我者。主事业、官非、压力、疾病（占事为事体本身）

## 用神取用

| 所问 | 用神 |
|---|---|
| 财/财运/生意 | 妻财 |
| 官运/事业/考试/官非 | 官鬼 |
| 婚姻/配偶 | 妻财（男占）或官鬼（女占） |
| 父母/长辈/房产/文书 | 父母 |
| 子女/晚辈 | 子孙 |
| 兄弟/朋友/合作 | 兄弟 |
| 自身/总体 | 世爻 |

六亲不全时以世应为核：世爻为求测者，应爻为所问之事。

## 旺衰判断原则

- **旺相**：用神得月建/日辰生扶（临月建、得日辰生、得动爻生）为旺
- **休囚**：用神受月建/日辰克泄为衰
- **动变**：动爻生用神为吉，动爻克用神为凶；变爻回头生/克用神是重要信号
- **三合局**：三爻成三合局力量大增
- **旬空**：用神逢空事未成，出空应事
- 旺衰等级：过旺 / 旺 / 平 / 衰 / 死——以 `strength` 输出为准，不得自行估算

## 应期常识

- 用神旺相逢生扶 → 应期近且顺；用神衰而待生 → 应期在生扶之时（值月/值日）
- 用神逢空 → 出空之日应事；用神逢冲 → 逢合之日应事（冲中逢合）
- 动爻应期：动而逢合/逢值之日
