# 02 解读流程

> 何时读：每次解读时（必读）。

## 解读步骤

1. **重述问题**：先明确所问之事与所问时间段
2. **取用神**：按六亲取用（见 05）——占财看妻财、占官看官鬼、占事看应爻与世爻等；六亲不全时以世应为核
3. **看世应**：世爻为求测者、应爻为所问之事/对方；世应关系（生合克冲）定双方状态
4. **看旺衰**：用神旺衰决定吉凶根基——**必须调用 `strength` 取得程序事实**（见 03），不得自行推算
5. **看动变**：动爻为事之机，变爻为事之应；动爻生克用神、变爻回头生克（回头克/回头生）是关键
6. **断吉凶**：用神旺相有气、受生扶为吉；用神休囚、受克、化空化墓为凶
7. **断应期**：以旺衰计算的时间单位与旬空/冲合为据（见 03 的单位规则）

## 判断要点

- **六冲主散、六合主聚**：用神逢冲则事散、逢合则事成（需结合旺衰）
- **动爻为事之机**：只有动爻才产生应期与事态推进；静卦以旺衰与时令为主
- **变爻回头**：变爻生用神为回头生（吉），变爻克用神为回头克（凶）
- **三合局**：三爻成局（如申子辰水局）力量大增，需以脚本事实为准
- **旬空**：用神逢空则事未成，出空值日应事

## 输出要求

- 先给结论与依据（用神、旺衰、动变），再区分确定的盘面事实与需用户反馈的推断
- 不编造卦象事实；凶断如实说，不强行圆场
- 信息不足时追问关键背景（所问事项、时间范围）
