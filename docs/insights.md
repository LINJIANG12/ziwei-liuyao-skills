# 命理心得

[README](../README.md) · [安装指南](../INSTALL.md)

> 本文档为作者个人的命理学习与实践心得，随本发布包一并公开。内容基于紫微斗数与六爻的长期实践整理，属个人经验之谈，供同好参考交流。

市面上你能找到的 90% 所谓的命理师，无论是东玄还是西玄，对你都没有真正的帮助。

且不说这些术数能否算准。就目前学易之人的平均素质而言，还不如稍微努力些的大学生。倘若真能算得多么厉害，早发大财了，谁不想过好日子？

尤其是西玄，最为乱七八糟。塔罗的门槛低到小学生都能拿副牌说自己会看。而东玄在坑蒙拐骗上更胜一筹：拿我认识的一个人来说，几年前 AI 还没有发力的时候，他就用排盘软件上的卦辞爻辞、可信度极低的断语给别人看卦。就这种水平，徒弟还收了七八个；他声称有徒弟的八字，可以找人做法对徒弟不利，以此威胁、骗财骗色。

当然，我也认识很多心性淳朴、真心学易的人，他们确实能断准吉凶，乃至简单的事情经过、走向。

但学了用了这么多年玄学，以我的经验来看，这本质上毫无用处，解决不了太多实际问题。

它能给你方向，但不能替你走路；能帮你看清一些东西，但不能替你决断。真正决定你人生走向的，还是你自己的智慧、判断力、执行力，还有身体和精神状态。

大多数人，只在事发之时才想着病急乱投医，经验丰富些的，简单沟通两句就能知道结果，根本不需要算，年轻问感情的，十有九是失败，问学业亦是如此。求财者无财，问运者多艰。命理师只要有看对50%信息的水平，就可以凭经验分析出过往经历和未来大概率的结果。再学上一些模棱两可的套话，准确率到百分之八九十都不难。能把人唬得一楞一楞。

可又有什么用呢。这种是无法看出真正的解法是什么的。或者说解法，但那不是求卜的想听到的。好好学习努力工作，或者是和合适但痴迷的对象决断、提升自己能力就一切迎刃而解等等。更何况上述说的在如今的圈子里还是较为厉害的了，大多数人能找到的还不如这个水平。

即使知晓了一件事情的结果，也做不到从中受益。如果一个人真这么笃信占卜结果——感情不吉就分手，得知某事不利就爽快放弃——那的确能得点小吉小利；但遇到重大抉择仍旧疯狂痴信占卜的，本质就是蠢。

我见过沉迷算来算去只为听自己想听的，或者是被卦象的结果左右到最后什么也没改变的。也见过从来不需要迷信这些玄学，但每一步都走得稳当的。前者把放弃了自己的命运，后者把命运攥在手里。

很多人能看准别人却看不透自己也是同理，对于自身术数最大的限制就是我执。看不破执念，占卜不过是借术数之口，得到自己想要的答案而已。而能破除执念、有能力掌控自己的人，也不需要占卜，自身的能力胜过一切。

所以不建议浪费钱去找人看了，除非你觉得自己有那个运气，能从一堆江湖骗子、三脚猫中找到真正有能力的。但技术能发挥多大作用，看的是用的人。
