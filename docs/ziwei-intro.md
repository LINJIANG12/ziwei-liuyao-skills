# 紫微斗数技能介绍（ziwei-agent）

[README](../README.md) · [安装指南](../INSTALL.md)

## 设计思路和主要工作
我没学过紫薇。所以不做过多介绍。
值得介绍的功能是时辰反推。在不清楚出生时辰的情况下可以输入您个人的过往信息，agent会调用工具获取对应的流年流月排盘，基于公开的基础知识库进行分析。个人小范围测试在完整知识库的情况下准确率很高。但未测试当前版本效果。

## 限制
极度依赖知识库，如果不加以限制让ai自己分析。可以说是乱编。我内置了基础的几十条规则，可以满足简单推算，全量有500多条暂时不公开。
取象依旧很差。但是在校准当前信息后对于一年内的事情判断还可以。（同样基于全量知识库）
