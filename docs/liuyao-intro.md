# 六爻技能介绍（liuyao-agent）

[README](../README.md) · [安装指南](../INSTALL.md)

## 设计思路和主要工作

六爻可以分做一卦多断和一事一卦两种，但是受限于目前的ai能力和知识库限制，采用一事一卦严禁分占的流派。出于防呆设计做了优化占问的功能（有时会过度限制）
取用神采用的是注入常见基础规则，再加上投喂资料由ai扩充，我校准微调后的提示词。在这里提供另一种简单的看吉凶方式：只以用神为用，不取象不分析含义。占问精确到做某事的吉凶，世旺则吉衰则凶。
制作了基础的排盘算法。流派以增删、卜筮正宗未核心。兼容部分易隐。有些冲突点以我个人习惯做了取舍。未引入神煞
核心功能是旺衰计算工具：正常断卦需要计算旺衰，这一步容易出错并且有些累人。于是做了一个自动计算旺衰的工具，底部会附带简略的计算规则
基于此的流月流日工具：依托于工具可调用任意时间的旺衰，对于推断应期，以月为单位的可以一次性获取12个月的旺衰情况以及入墓合冲等信息。（可能会有bug），以此快速推断。避免模型空耗注意力，一般来说模型也算不准。计算规则是我自己的习惯。可能和很多人的旺衰判断情况由细节上的区别。可以自己二次开发。注明来源不商用就好了

## 限制
取象严重受限知识库。我并未开源自用知识库，当前版本基本是模型乱编。
对于小众问题取用神可能会出错，意味着整个卦得信息判断、吉凶推断都是错的。有经验得可以指定用神来调整，但是对于大部分用户，不建议过度相信模型判断。
起卦最佳是手摇，怎么摇网上由教程，其次是模拟手摇，再是随机起卦。只有卦准才有解对的可能，一定程度上不稳定。
## 旺衰计算工具规则

一、基础框架
力量基线：每爻初始 50 分，由时间柱（月建/日辰/时柱，按查询范围启用）逐项加减，再经爻间作用、动变、合冲墓等修正，最终映射等级：

等级	分值
过旺	≥ 90
旺	≥ 60
平	≥ 35（有效力量门槛）
衰	> 0
死	= 0
启用柱规则（按问题时间范围）：

年/月内（annual/monthly/five_day）→ 月建 + 日辰计力，时柱只作应期
日内（intra_day）→ 日辰 + 时柱计力，不重新启用月建
二、时间柱力量（四柱贡献）
对每爻（以爻五行为准，与月日柱五行生克）：

关系	分值
临（柱支=爻支）	+20
生 / 比	+15
克	−15
泄 / 制	0（不改变力量）
六冲（柱支与爻支相冲）统一按冲损：15 × 4/3 = 20 点损害（同属性比冲 ×2/3 ≈ 13.3），与冲对双方五行生克方向无关（寅申/巳亥等「制/泄」方向同样削弱，避免同一对六冲谁冲谁结果不同）
六合：合而不损（保留柱的加力）
临月/临日保护：被保护的爻力量下限 35（平级保护，回头生克无法打落保护中的爻）；旺/过旺仍按 60/90 分级
三、计算顺序（官方 9 步）
按问题时间范围选启用柱；timingOnly 柱只作应期
每爻以 50 为基线，算启用柱的临/生/比/克（泄制不计）
合并基础力量；临月/临日保护下限 35；旬空只作限制不改力量
暗动识别：按未受日冲损害的基础力量，日辰冲旺的静爻形成暗动；成功暗动不承受该次日冲损害，显性动爻按动静层级处理
变爻回头作用：动爻的变爻对同位置本爻回头生/克/泄/制 + 合冲；动爻当前力量含该回头作用（尚未应用外部墓锁）
入墓/墓锁：用含动化结果的冻结来源集合，识别「月日或最终力量 ≥ 平级(35) 的动爻」形成的外部墓地；算入墓、墓锁与冲墓/合墓解除；同轮墓锁不递归创造新墓源
六合绑定：按生合/比合/克合识别；克合门槛 = 克方比被克方强 ≥ 10 点；有效六合建立运行时绑定——绑定成员保留自身力量但不再参与对外爻间作用或三合
动爻/暗动作用：非旬空、非入墓、不为死的动爻/暗动产生爻间作用；平、衰动爻也可作用，来源耗尽后停止
三合局：识别完整三合（申子辰水/亥卯未木/寅午戌火/巳酉丑金）加力 +30；半局只记为待成局，不产生作用；最后重新汇总映射等级
四、爻间作用（动爻对静爻/动爻）

基础作用 = (来源力量 / 50) × 10
力量差缩放 = 1 ± (来源力量 − 目标力量) / 100
目标增量 = 生/比 → +基础×缩放；克 → −基础×缩放（比 = 等量转移 100%）
来源消耗 = 基础 × (1 ∓ 力量差/100)；冲损按冲规则；六合不产生爻间作用
静爻不作为普通生克来源；作用链只从动爻/暗动出发
来源力量耗尽（减到无效）即停止继续作用
